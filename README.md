# 초성퀴즈

동물, 음식, 사물 세 카테고리에서 초성 문제를 풀 수 있는 정적 웹 앱입니다. 외부 라이브러리나 빌드 과정 없이 동작합니다.

## 실행

`index.html`을 브라우저에서 열거나, 이 폴더에서 다음 명령으로 로컬 서버를 실행하세요.

```sh
python3 -m http.server 4173
```

그다음 `http://localhost:4173`을 여세요.

## 게임 규칙

- 카테고리마다 서로 다른 문항 100개가 있습니다.
- 한 문제 제한 시간은 30초입니다.
- 정답을 맞히면 100점을 얻습니다.
- 힌트를 사용하면 50점이 차감됩니다.
- 정답을 맞히거나 시간이 끝나면 다음 문제 버튼으로 포커스가 이동하고, Enter를 눌러 다음 문제로 진행할 수 있습니다.
- 시작 창에서 플레이어 이름, 동물·음식·사물 카테고리, 20·30·50문제 중 한 가지를 선택합니다. 이름과 선택은 이 브라우저에 저장되고 다음 방문 때 불러옵니다. 한글 이름 입력 중 조합이 완료되기 전에 폼이 제출되지 않도록 처리합니다.
- 선택한 수만큼 카테고리 문항을 첫 문제부터 무작위 순서로 출제합니다.
- 점수 옆에는 현재 카테고리에서 맞힌 문항 수와 선택한 전체 문항 수를 표시합니다. 카테고리를 바꾸면 점수와 정답 수가 초기화됩니다.
- 남은 시간이 10초 이하가 되면 문제 아래 안내 영역에 문항의 세부 분류를 보여줍니다.
- 마지막 문항 다음에는 문제 영역에 최종 점수와 맞힌 문항 수를 표시합니다.
- 모바일에서는 정답 입력란을 선택해 기기의 한글 키보드로 답을 입력합니다.

## 배포

Netlify 무료 팀에 배포되어 있습니다.

- 프로젝트 이름: `choseong-quiz-clack`
- 플레이 주소: https://choseong-quiz-clack.netlify.app
- Netlify 프로젝트: https://app.netlify.com/projects/choseong-quiz-clack
- 다른 컴퓨터에서 배포할 때는 Netlify CLI 로그인 후 `netlify link`로 이 프로젝트를 한 번 연결하고, `netlify deploy --prod --dir .` 명령을 실행합니다.
